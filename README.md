# PSHT Bandar Sakti Website

The website for **PSHT Bandar Sakti**, a local branch of Persaudaraan Setia Hati Terate (PSHT), an Indonesian martial arts brotherhood. It tells visitors what PSHT is, what it teaches, how to join training, and where to find the group.

The site content is in Indonesian.

## What's on the site

- **About**: who PSHT is and its values
- **Philosophy**: the teachings behind the martial art
- **Training**: how to join as a new member
- **Location**: an embedded Google Map of the training ground
- **Contact**: the core committee and the secretariat
- Smooth scrolling, a mobile menu, and a layout that works on phones

## Tech stack

HTML, CSS, JavaScript. No build step and no server needed.

## Run it

Open `index.html` in your browser. That's it.

To publish it, upload the three files (`index.html`, `styles.css`, `script.js`) to any static host, such as GitHub Pages or Netlify.
