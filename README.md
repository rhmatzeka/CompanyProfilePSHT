# 🥋 Website Resmi PSHT Ranting Bandar Sakti

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Status: Live](https://img.shields.io/badge/Status-Live-green.svg)]()

Website resmi Persaudaraan Setia Hati Terate (PSHT) Ranting Bandar Sakti. Tujuan website ini adalah untuk menyediakan informasi dasar mengenai PSHT Ranting Bandar Sakti, sejarah, visi misi, serta kontak bagi anggota dan masyarakat umum.

---

## 🚀 Fitur Utama

* **Informasi Organisasi:** Profil singkat PSHT, sejarah, dan tujuan.
* **Visi & Misi:** Penjelasan mengenai visi dan misi ranting.
* **Galeri Foto:** Bagian untuk menampilkan kegiatan atau dokumentasi foto (jika ada).
* **Halaman Kontak:** Informasi kontak dan lokasi latihan.
* **Desain Responsif (Opsional):** Tampilan yang menyesuaikan di berbagai perangkat.

---

## 🛠️ Teknologi yang Digunakan

| Kategori | Bahasa / Teknologi | Deskripsi |
| :--- | :--- | :--- |
| **Markup** | **HTML5** | Struktur dasar halaman web dan konten teks. |
| **Styling** | **CSS3** | Penataan tampilan, warna, *layout*, dan font agar sesuai dengan identitas PSHT. |
| **Logika (Opsional)** | **JavaScript (ES6+)** | Dapat digunakan untuk fitur interaktif kecil seperti galeri gambar atau menu *dropdown*. |
| **Hosting** | **GitHub Pages / Netlify** | Platform untuk menghosting website statis ini secara gratis. |
| **Platform Awal** | **Page.gd (untuk referensi)** | Website asli dibangun menggunakan platform website builder Page.gd. |

## 💻 Instalasi dan Penggunaan (Jika Dibuat Manual)

Jika Anda ingin membuat ulang website ini sebagai proyek statis HTML/CSS/JS, ikuti langkah-langkah berikut:

1.  **Kloning Repositori:**
    ```bash
    git clone [https://github.com/username-anda/psht-bandar-sakti-website.git](https://github.com/username-anda/psht-bandar-sakti-website.git)
    ```
2.  **Masuk ke Direktori Proyek:**
    ```bash
    cd psht-bandar-sakti-website
    ```
3.  **Buka di Browser:**
    Buka berkas `index.html` langsung di browser Anda untuk melihat tampilannya.
